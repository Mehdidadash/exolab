# ExoLab — وب‌سایت لابراتوار دیجیتال دندانسازی

سیستم مدیریت جامع کیس، فاکتور، پرداخت، برچسب‌زنی و نوتیفیکیشن برای لابراتوار دندانسازی دیجیتال.

---

## وضعیت فعلی (July 2026)

پروژه در مرحله تولید است. اکثر ماژول‌ها کامل شده‌اند.

---

## ویژگی‌ها

### سایت عمومی (`index.php`, `contact.php`)
- صفحه اصلی با معرفی خدمات، لیست قیمت و نمونه کارها
- گالری تصاویر با لایت‌باکس
- نقشه و مسیریابی دو شعبه (اسلامشهر و قزوین)

### پنل مدیریت (`panel/`)

| ماژول | توضیحات |
|-------|---------|
| **احراز هویت** | ورود با کپچا (بعد از ۳ تلاش ناموفق)، محدودیت تلاش تدریجی، نشست ۶۰ روزه |
| **مدیریت نقش‌ها** | جدول `roles` با مجوزهای پویا — از طریق پنل قابل مدیریت |
| **مدیریت کاربران** | ۱۵+ نقش شامل مدیر، پزشک، منشی، طراح، لابراتوار (برونسپاری/مشتری/همکار)، کلینیک و... |
| **مدیریت کیس‌ها** | ثبت/ویرایش/حذف، فیلتر، سرچ، آپلود فایل (STL/PLY/stp/obj/3mf + تصاویر + zip/rar) |
| **زیرمجموعه کیس** | قابلیت تعریف کیس زیرمجموعه (parent_id) برای پروتزهای چندبخشی |
| **برونسپاری** | انتساب کیس به لابراتوار خارجی با دسترسی محدود |
| **طراح** | انتساب طراح به کیس با نوتیفیکیشن خودکار |
| **نمایشگر سه‌بعدی** | نمایش STL/PLY با Three.js + چرخش/زوم/رزت |
| **مدیریت فاکتورها** | ایجاد دستی + صدور فاکتور ماهانه خودکار، ویرایش با انتخاب کیس، تخفیف، PDF |
| **مدیریت پرداخت‌ها** | ثبت با روش‌های مختلف، اتصال به فاکتور |
| **حساب بانکی** | تعریف چند حساب برای درج در فاکتور PDF |
| **قیمت‌های اختصاصی** | قیمت متفاوت به ازای هر پزشک |
| **چاپ برچسب** | انتخاب گروهی کیس‌ها + تولید PDF با QR کد (دو ستون A4) |
| **تغییر وضعیت گروهی** | انتخاب چند کیس و تغییر وضعیت یکجا |
| **خروجی CSV** | خروجی کیس‌های انتخاب شده برای لابراتوار (بدون نام دکتر) |
| **نمایه پزشک** | صفحه اختصاصی با آمار کیس‌ها، فاکتورها و پرداخت‌ها |
| **سلسله‌مراتب کلینیک** | کلینیک می‌تواند کیس‌ها و فاکتورهای پزشکان زیرمجموعه را ببیند |
| **نوتیفیکیشن** | سیستم داخلی + ایمیل — هنگام انتصاب لابراتوار/طراح |
| **لاگ فعالیت‌ها** | ثبت خودکار همه عملیات‌ها (create/update/delete) |
| **داشبورد** | آمار کلی: کیس‌ها، پزشکان، کاربران، فاکتورها، درآمد |

### امنیت
- رمز عبور با `password_hash()` + `password_verify()`
- CSRF Protection در تمام فرم‌ها (POST + Header)
- Rate limiting + کپچا در ورود
- Prepared statements برای همه کوئری‌ها
- دسترسی نقش‌ها از دیتابیس (`roles` table)
- مخفی‌سازی فیلدهای لابراتوار/طراح برای پزشکان و کلینیک

### نمونه کارها
- `panel/works.php` — فهرست نمونه کار
- `panel/work_form.php` — فرم ایجاد/ویرایش نمونه کار
- `panel/save_work.php` — ذخیره تصویر و داده نمونه کار
- `panel/delete_work.php` — حذف نمونه کار

### پزشکان
- `panel/doctors.php` — فهرست پزشکان
- `panel/doctor_form.php` — فرم پزشک
- `panel/save_doctor.php` — ذخیره یا بروزرسانی پزشک
- `panel/delete_doctor.php` — حذف پزشک

### فاکتورها
- `panel/invoices.php` — لیست فاکتورها
- `panel/invoice_form.php` — ایجاد/ویرایش فاکتور با آیتم‌های قابل اضافه شدن
- `panel/save_invoice.php` — ذخیره فاکتور و آیتم‌های آن
- `panel/delete_invoice.php` — حذف فاکتور
- `panel/invoice_pdf.php` — تولید PDF فاکتور با تاریخ و اعداد فارسی

### پرداخت‌ها
- `panel/payments.php` — لیست پرداخت‌ها
- `panel/payment_form.php` — ثبت یا ویرایش پرداخت با لینک فاکتورها
- `panel/save_payment.php` — ذخیره پرداخت و ارتباط با فاکتورها
- `panel/delete_payment.php` — حذف پرداخت

### حساب‌های بانکی
- `panel/bank_accounts.php` — لیست حساب‌ها
- `panel/bank_account_form.php` — فرم حساب بانکی
- `panel/save_bank_account.php` — ذخیره اطلاعات حساب
- `panel/delete_bank_account.php` — حذف حساب

## جریان فاکتورها
1. فاکتور جدید در `panel/invoice_form.php` ایجاد می‌شود.
2. کاربر شماره فاکتور، اطلاعات دکتر یا انتخاب دکتر از فهرست، تاریخ فاکتور، تاریخ سررسید و موارد فاکتور را وارد می‌کند.
3. `save_invoice.php` داده‌ها را بررسی می‌کند و با کمک `db.php` فاکتور را در `doctor_invoices` ذخیره می‌کند.
4. آنالیز آیتم‌ها انجام شده و هر مورد در `invoice_items` ذخیره می‌شود.
5. مبلغ کل فاکتور به صورت خودکار از مجموع آیتم‌ها محاسبه می‌شود.
6. در صفحه `panel/invoices.php` می‌توان فاکتور را ویرایش، حذف یا پیش‌نمایش PDF گرفت.
7. پرداخت‌ها در `panel/payment_form.php` ثبت شده و می‌توان آن‌ها را به فاکتورها لینک داد.
8. لینک پرداخت به فاکتورها در جدول `doctor_payment_invoices` ذخیره می‌شود.

## نکات مهم
- سیستم تاریخ‌ها را به صورت شمسی و فارسی نمایش می‌دهد، ولی تاریخ‌ها در پایگاه داده به فرمت میلادی (`YYYY-MM-DD`) ذخیره می‌شوند.
- `db.php` با PDO به پایگاه داده متصل می‌شود و از `prepared statements` استفاده می‌کند.
- `panel/auth.php` از سشن برای کنترل دسترسی مدیر استفاده می‌کند.
- `site_prices.display_order` در زمان اجرا بررسی و در صورت نیاز اضافه می‌شود.
- `invoice_pdf.php` از `mpdf` برای تولید PDF با راست‌چین و تاریخ فارسی استفاده می‌کند.

## پیشنهادات برای بهبود
- مدیریت کاربران و تغییر رمز عبور مدیر را اضافه کنید.
- رمزهای عبور را به صورت هش شده ذخیره کرده و ورود را امن‌تر کنید.
- محافظت در برابر CSRF برای فرم‌های POST اضافه شود.
- بازبینی و تفکیک لایه‌های داده، منطق و نمایش (MVC یا سرویس‌ها) را انجام دهید.
- یک اسکریپت نصب یا مهاجرت پایگاه داده بسازید تا وابستگی به فایل‌های دستی کاهش یابد.
- اعتبارسنجی سمت سرور و سمت کاربر را بهبود بدهید.
- نمایش فاکتور و پرداخت‌ها را با گزارش‌های جمعی و اکسل/CSV گسترش دهید.
- وضعیت پرداخت فاکتور را بر اساس پرداخت‌های مرتبط به‌صورت خودکار محاسبه کنید.

## نصب و راه‌اندازی
1. `composer install`
2. فایل `config.php` را با اطلاعات دیتابیس خود به‌روزرسانی کنید.
3. جداول مورد نیاز را در دیتابیس بسازید یا از فایل مهاجرت موجود استفاده کنید.
4. `panel/login.php` را از طریق مرورگر باز کنید.
